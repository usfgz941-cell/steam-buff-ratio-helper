# 版本验收检查清单

每次 Tampermonkey 脚本更新后，用一件低价饰品先跑完整链路。

## 环境

- [ ] Tampermonkey 已启用
- [ ] Steam 已登录
- [ ] Steam 钱包货币与预期一致
- [ ] 脚本版本与 GitHub 最新版本一致

## CSV

- [ ] 可以导入 BUFF CSV
- [ ] 导入记录数合理
- [ ] 再次导入不会重复增加相同记录
- [ ] 已售状态仍保留

## 成本匹配

- [ ] 当前饰品能匹配到正确名称
- [ ] 历史买入成本正确
- [ ] 同名多笔可以切换
- [ ] FIFO 默认选择合理
- [ ] 标记已售后下一笔成本推进正常

## Steam 金额

- [ ] 输入“买家支付”后 Steam “您收款”正常变化
- [ ] 脚本读取的买家支付与页面一致
- [ ] 脚本读取的您收款与页面一致
- [ ] UAH 整数价格没有多乘 / 少乘 100

## 比例

- [ ] 实际比例与手算一致
- [ ] 比例 ≤ 底线时显示通过
- [ ] 比例 > 底线时显示警告
- [ ] 底线反推价合理

## 市场

- [ ] 当前卖盘能读取
- [ ] 同价位聚合数量正确
- [ ] 近期成交可用时能显示
- [ ] 近期成交不可用时能正常降级

## 推荐价

- [ ] 快速价不突破比例底线
- [ ] 均衡价符合当前盘口直觉
- [ ] 耐心价不低于均衡价
- [ ] 点击推荐价只填入价格，不自动确认出售

## 安全

- [ ] 没有自动勾选协议
- [ ] 没有自动点击最终出售
- [ ] 没有要求 Steam Cookie / API Key
- [ ] 没有向公开仓库提交个人 CSV
