# 常见问题与排错

## 1. Steam 页面没有“挂刀助手”

检查顺序：

1. Tampermonkey 是否已启用；
2. 脚本是否启用；
3. 当前页面是否是 `steamcommunity.com` 的库存 / 市场页面；
4. 刷新页面；
5. 打开开发者工具 Console，搜索 `[挂刀助手]`。

## 2. 导入 CSV 后显示 0 条

确认：

- CSV 是 BUFF 的购买记录导出，而不是出售记录；
- 文件不是被 Excel 另存为破坏格式的特殊编码；
- 至少存在“交易成功”的记录；
- 表头仍包含饰品、时间、交易状态、价格等字段。

如果仍失败，保留表头和 2~3 条脱敏样例即可排查，不要公开完整个人 CSV。

## 3. 没有匹配到成本

可能原因：

- Steam 显示英文名，BUFF 记录是中文名；
- 名称格式存在差异；
- 同名但磨损写法不同；
- 当前饰品不在导入的时间范围内。

处理：

1. 确认 CSV 中确实有这笔购买；
2. 尝试切换 Steam 界面语言；
3. 查看成本候选下拉框；
4. 记录具体 Steam 名称与 BUFF 名称，后续加入别名映射。

## 4. 匹配到了错误成本

同名多件默认使用 FIFO，因此实例对应关系可能不是 100% 自动恢复。

直接在成本下拉框手动选择正确历史记录即可。

出售后记得标记已售。

## 5. 比例与手算不一致

先确认计算口径一致：

```text
脚本比例 = BUFF 历史实际买入价 × CNY→UAH 汇率 / Steam “您收款”
```

常见差异来源：

- 你手算用了“买家支付”而不是“您收款”；
- 使用了不同汇率；
- 第三方插件使用的是当前 BUFF 市价，而不是历史买入价；
- Steam UAH 手续费存在整数取整。

判断优先级：

```text
Steam 实际“您收款” > 脚本手续费估算 > 第三方估算
```

## 6. 推荐价读不到

推荐价依赖 Steam 当前卖盘接口。

可能原因：

- Steam 临时限流；
- 市场接口返回空数据；
- 当前饰品没有 market_hash_name；
- 网络问题。

可以点击 **刷新市场** 重试。

即使推荐价暂时不可用，历史成本 + 实时比例仍应可以使用。

## 7. 近期成交历史不可用

脚本会降级：只使用当前卖盘深度计算建议，不会因此阻止实时比例功能。

面板会提示：

> 近期成交数据不可用，建议仅按当前卖盘深度估算

## 8. 点推荐价后 Steam 金额没有联动

脚本只负责填入“买家支付”，随后会尝试调用 Steam 原生价格联动逻辑。

如果 Steam 页面结构变化，可能出现：

- 买家支付被填入；
- 但“您收款”没有立即变化。

这时手动在价格框按一次键或重新输入最后一位，并把 Console 中相关报错记录下来。

## 9. 汇率获取失败

默认汇率来自 NBU。

如果 NBU 请求失败：

1. 重新刷新汇率；
2. 或在设置中切换为手动 CNY→UAH 汇率。

实时比例必须有汇率才能跨币种计算。

## 10. 更新后脚本异常

1. 查看脚本版本；
2. 查看 `CHANGELOG.md`；
3. 在 Tampermonkey 中重新检查更新；
4. 刷新 Steam；
5. 如果问题持续，记录：
   - Steam 出售窗口截图；
   - 挂刀助手面板截图；
   - Console 中 `[挂刀助手]` 相关内容；
   - 当前脚本版本。

## 11. 建议反馈格式

为了快速定位问题，建议提供：

```text
脚本版本：
Steam 页面语言：
Steam 钱包货币：UAH / 其他
饰品名称：
BUFF 成本是否匹配：是 / 否
买家支付：
您收款：
脚本显示比例：
预期比例：
市场推荐是否显示：是 / 否
Console 错误：
```

不需要提供 Steam 密码、Cookie、API Key。
