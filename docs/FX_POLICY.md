# 汇率口径策略

## 比例到底在衡量什么

跨币种挂刀比例本质是：

```text
人民币现金成本 / 人民币等价的 Steam 钱包到账价值
```

因此，比例不仅取决于饰品价格和 Steam 手续费，也取决于“1 元人民币究竟值多少 UAH Steam 余额”的估值口径。

## 三种模式

### 实际成本汇率（推荐）

用户填写自己实际获取 UAH / Steam 余额时的综合汇率，包含支付渠道、点差和手续费。

适合回答：

> 这次现金换余额，我真实付出了多少人民币？

### NBU 参考汇率

由乌克兰国家银行官方汇率提供统一、可复现的参考值。

适合：

- 长期比较不同饰品；
- 没有实际渠道汇率时使用；
- 作为辅助基准。

不应把它标成“真实成本汇率”。

### Steam 隐含汇率

通过 Steam 跨币种展示或钱包元数据观察到的内部换算关系。

适合诊断 Steam 的显示和市场转换，不代表现实中可兑换的现金汇率。

## UI 要求

比例旁必须显示：

- 汇率模式；
- 当前数值；
- 更新时间；
- 是否为手动值；
- 数据过期提示。

示例：

```text
实际比例：0.647
汇率：实际成本（手动） ¥1 = ₴6.65
更新时间：2026-08-24 03:10
```

## 决策原则

- 底线判断默认采用“实际成本汇率”。
- 没有实际汇率时，可回退到 NBU，但必须显示“参考”。
- 推荐价可以同时显示 NBU 比例和实际成本比例，不能把两者混成一个数字。
- 汇率变化只改变余额的人民币估值，不改变 Steam 账户里实际收到的 UAH。
