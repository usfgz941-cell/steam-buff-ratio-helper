# 安装与第一次使用

## 1. 安装 Tampermonkey

在 Edge / Chrome 中安装 Tampermonkey，并确认扩展已启用。

## 2. 安装脚本

打开：

https://raw.githubusercontent.com/usfgz941-cell/steam-buff-ratio-helper/main/steam_buff_ratio_helper.user.js

Tampermonkey 应识别为用户脚本。确认安装后，回到 Steam 库存页面并刷新。

### 安装成功的判断

Steam 库存页右下角应出现：

> 挂刀助手

如果没有出现，先看 [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md)。

## 3. 导入 BUFF 购买记录

1. 在 BUFF 导出购买记录 CSV。
2. Steam 库存页点击右下角 **挂刀助手**。
3. 点击 **导入 / 更新 CSV**。
4. 选择 BUFF 导出的购买记录 CSV。
5. 确认导入条数与未售记录数合理。

以后有新购买记录时，重新导出完整 CSV 再导入即可；脚本会自动合并、去重。

> 不要把自己的 BUFF CSV 上传到这个公开 GitHub 仓库。CSV 可能包含 Steam ID、交易时间和个人购买记录。

## 4. 设置比例底线与汇率

默认设置：

- 比例底线：`0.70`
- 汇率：NBU 官方 CNY→UAH
- 推荐模式：均衡
- 卖盘读取数量：20

`0.70` 表示“实际比例不能高于 0.70”。比例越低，现金换 Steam 余额的效率越高。

## 5. 打开出售窗口

在 Steam 库存中选择一件 CS2 饰品并点击出售。

脚本会尝试：

1. 读取当前饰品名称与 market_hash_name；
2. 在本地 BUFF 购买记录中匹配历史成本；
3. 若同名有多笔，默认选择最早未售记录（FIFO）；
4. 读取当前 Steam 卖盘与近期成交历史；
5. 显示比例与三档建议价。

若匹配到的成本不对，可以直接在成本下拉框切换到正确记录。

## 6. 输入“买家支付”

你只需要在 Steam 原生出售窗口的 **“买家支付”** 输入想挂的价格。

Steam 会自动计算 **“您收款”**，脚本再使用该实际到账计算：

```text
实际比例 = BUFF 实际成本（折合 UAH） / Steam 实际到账 UAH
```

例如：

```text
BUFF 成本：¥4.96
¥1 = ₴6.65
买家支付：₴59
Steam 您收款：₴51
实际比例 ≈ 0.647
```

比例显示：

- `≤ 0.70`：在底线以内；
- `> 0.70`：超过底线，不建议主动继续压低售价。

## 7. 查看推荐挂价

当前提供三档：

- **快速**：偏成交速度；
- **均衡**：在排队数量和比例之间平衡；
- **耐心**：更倾向较高售价 / 更低比例。

点击推荐价格只会把价格填入 **“买家支付”**。

**不会：**

- 自动勾选 Steam 协议；
- 自动点击确认；
- 自动完成手机确认。

推荐算法详细说明：[`ALGORITHM.md`](ALGORITHM.md)。

## 8. 第一次实测建议

第一次不要直接拿高价饰品测试。用一件低价、成本明确的饰品，确认以下四项：

- [ ] BUFF 实际成本匹配正确
- [ ] 输入买家支付后，“您收款”读取正确
- [ ] 比例会实时变化
- [ ] 当前卖盘与推荐价能够显示

四项都正常后，再用于正常挂刀。

## 9. 卖出后怎么处理成本

出售成功后，在脚本里把对应 BUFF 成本记录 **标记已售**。

这样同名多件饰品后续会继续按 FIFO 选择下一笔未售成本。

## 10. 更新脚本

脚本 metadata 已配置 GitHub `@updateURL` / `@downloadURL`。Tampermonkey 可从主分支检查更新。

若更新后行为异常：

1. 先刷新 Steam 页面；
2. 打开 Tampermonkey 确认版本；
3. 查看 GitHub `CHANGELOG.md`；
4. 按排错文档导出截图 / Console 信息。

## 11. 数据安全

- BUFF CSV 和已售状态保存在 `steamcommunity.com` 的浏览器本地存储中。
- 脚本不读取 Steam 密码、Cookie、API Key。
- 不自动出售，不代替手机确认。
- 汇率默认从乌克兰国家银行 NBU 获取，也可改为手动汇率。

更多说明见 [`../SECURITY.md`](../SECURITY.md)。
